更新日志

0.1.15

2026-11-21
  • 显示器唤醒后录像不再冻住：屏幕采集停止给新画面时（录像里一直是同一张旧图），录制程序会重新开始采集。声音恢复后设置里的声音警告会自动消失；声音被卡住的那段录像用静音补齐，不再比画面短；显示器关着时不再切出大量很短的分段。

0.1.14

2026-11-20
  • 所有图标按钮和播放键都有了提示，淡入淡出，在相邻按钮之间移动时提示滑动跟随；快捷键以键帽显示（Space、J / L、F、M、C、Ctrl+Z / Ctrl+Y、[ / ]、Esc）。文字垂直居中更准确，回放窗口及时释放不再使用的内存。

0.1.13

2026-11-20
  • 剪辑模式：单击剪辑框的左右边，播放头直接跳到剪辑开头或结尾（按住拖仍是调整剪辑）；拖动播放头会吸附到剪辑两端；Home / End 跳到剪辑开头和结尾。

0.1.12

2026-11-20
  • 修复回放声画不同步：修复卡顿后音频队列死锁导致的 150 ms 反复回弹、高 GPU 负载下硬解队列堆积导致的画面滞后，以及往回跳转时声音先于画面起播的问题。
  • 大幅降低回放窗口空闲占用：窗口记录改为进入剪辑模式才懒加载，应用与标记日志改为增量读取，消除周期性卡顿并显著减少内存与 CPU 占用。
  • 隐藏后台录制进程的音量混合器条目：Windows 音量混合器不再同时出现两个 ScreenReplay 图标。
  • 修复回放窗口右上角保存完成卡片无法点击的问题，并优化「打开位置 / Show in folder」按钮的排版间距。

0.1.11

2026-11-20
  • HDR 屏幕：显示器关着时启动录制，录像不再发白，会沿用上次记下的 SDR 内容亮度。

0.1.10

2026-11-20
  • 回放时声画同步：回放窗口会扣除声卡的输出延迟，画面不再比声音早约 30 毫秒（用蓝牙耳机时差得更多）。

0.1.9

2026-11-20
  • 官网独立安装包支持自动更新：内置 ECDSA P-256 发布签名校验与 SHA-256 完整性校验，空闲时在后台静默下载并完成更新；「设置 › 关于」新增检查更新按钮与自动更新开关。

0.1.8

2026-11-19
  • 画面可以放大查看：在画面上按住 Ctrl 滚动滚轮（或在触控板上双指捏合），以鼠标位置为中心放大，最多 8 倍；放大后拖动画面平移，点右上角的「适应窗口」或按 0 键还原。保存的片段始终是整幅画面。

0.1.6

2026-11-19
